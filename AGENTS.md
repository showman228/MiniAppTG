# AGENTS.md

Этот проект — пет-проект. Главные приоритеты: **простота кода, скорость разработки, минимум лишних абстракций**.

## 1. Стек и технологии
* **Язык/Версия:** [Python 3.13.6]
* **Фреймворк:** [FastAPI]
* **База данных:** [PostgreSQL]

## 3. Правила написания кода (Coding Rules)
* **Чистота важнее перфекционизма:** Пиши рабочий код прямолинейно, избегай чрезмерного энтерпрайза (DI-контейнеров, фабрик фабрик и т.д.).
* **Типизация:** В Python — аннотации типов везде.
* **Обработка ошибок:** Пиши понятные логи и ранние возвраты (early return), избегай глубокой вложенности `if/else`.
* **Следовать Todo.txt** знак ✅ означает что данный пункт реализован; ❌ означет не реализован по какой то причине, после знака есть пояснение в кргулых скобках

## 4. Что НЕЛЬЗЯ делать
* Не добавляй новые тяжелые зависимости (npm/pip пакеты/poetry пакеты) без крайней необходимости. Сначала проверь, можно ли решить задачу встроенными средствами.
* Не удаляй существующие комментарии и чужой рабочий код, если это не требуется для задачи.
* Не пиши код «на будущее» (YAGNI — You Aren't Gonna Need It).
* Не коммитить измененения и переключаться самому менжду ветками без разрешения
